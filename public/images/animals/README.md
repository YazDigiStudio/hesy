## Image Requirements:

- Format: JPG or PNG
- Recommended size: 800x600px or larger
- Aspect ratio: 4:3 or 16:9
- File naming: lowercase, use hyphens (animal-name-number.jpg)

For development, using placeholder images from https://placecats.com or https://placedog.net
